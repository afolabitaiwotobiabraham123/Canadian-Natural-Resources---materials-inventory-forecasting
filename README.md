##  Problem Statement

Maintaining sufficient inventory is important for supporting field operations.

Too little inventory can create shortages, while excessive inventory can increase carrying costs and tie up working capital.

The analytical question is:

> **Can historical materials consumption and inventory data be used to identify shortages, excess inventory, and future demand patterns?**

---

##  Proposed Solution

I plan to build an:

### **Oilfield Materials Demand & Inventory Forecasting System**

The system will analyse historical demand and inventory patterns to support:

* Demand forecasting
* Inventory monitoring
* Stockout identification
* Excess inventory identification
* Reorder planning

---

##  Key Analytical Questions

1. Which materials have the highest consumption?
2. Which materials experience volatile demand?
3. Which materials are frequently out of stock?
4. Which materials appear to have excess inventory?
5. What are the monthly/weekly demand patterns?
6. Which materials require higher safety-stock attention?
7. Can historical demand be used to forecast future requirements?
8. Which materials should receive greater inventory-planning attention?
